# 타이포그래피 토큰

모든 타이포그래피 토큰은 스킨 변수(`--skin-font-size-*`, `--skin-font-weight-*` 등)로 정의됩니다.
Tailwind의 `text-*`, `font-*`, `leading-*`, `tracking-*` 클래스가 스킨 토큰으로 위임됩니다.

---

## 폰트 크기

<div style={{ display: 'flex', flexDirection: 'column', gap: '12px', maxWidth: '600px' }}>
  {[
    { cls: 'text-xs', label: 'xs (0.75rem · 12px)', sample: '가나다 ABC abc 0123' },
    { cls: 'text-sm', label: 'sm (0.875rem · 14px)', sample: '가나다 ABC abc 0123' },
    { cls: 'text-base', label: 'base (1rem · 16px)', sample: '가나다 ABC abc 0123' },
    { cls: 'text-lg', label: 'lg (1.125rem · 18px)', sample: '가나다 ABC abc 0123' },
    { cls: 'text-xl', label: 'xl (1.25rem · 20px)', sample: '가나다 ABC' },
    { cls: 'text-2xl', label: '2xl (1.5rem · 24px)', sample: '가나다 ABC' },
    { cls: 'text-3xl', label: '3xl (1.875rem · 30px)', sample: '가나다 ABC' },
    { cls: 'text-4xl', label: '4xl (2.25rem · 36px)', sample: '가나다' },
  ].map(({ cls, label, sample }) => (
    <div key={cls} style={{ display: 'flex', alignItems: 'baseline', gap: '16px' }}>
      <div style={{ width: '200px', fontSize: '11px', color: 'var(--color-text-muted)', fontFamily: 'monospace' }}>{cls} · {label.split('(')[1].replace(')', '')}</div>
      <span className={cls} style={{ color: 'var(--color-text)' }}>{sample}</span>
    </div>
  ))}
</div>

      <span className={`text-base ${cls}`} style={{ color: 'var(--color-text)' }}>{sample}</span>

## 행간 (Line Height)

<div style={{ display: 'flex', gap: '24px' }}>
  {[
    { cls: 'leading-tight', label: 'tight (1.25)', text: '첫 번째 줄\n두 번째 줄\n세 번째 줄' },
    { cls: 'leading-normal', label: 'normal (1.5)', text: '첫 번째 줄\n두 번째 줄\n세 번째 줄' },
    { cls: 'leading-relaxed', label: 'relaxed (1.625)', text: '첫 번째 줄\n두 번째 줄\n세 번째 줄' },
  ].map(({ cls, label, text }) => (
    <div key={cls} style={{ flex: 1 }}>
      <code style={{ fontSize: '11px', color: 'var(--color-text-muted)' }}>{cls} · {label}</code>
      <div className={`text-sm ${cls} mt-2`} style={{ color: 'var(--color-text)', whiteSpace: 'pre-line', borderLeft: '2px solid var(--color-border)', paddingLeft: '8px' }}>{text}</div>
    </div>
  ))}
</div>

## Typography 컴포넌트 variant 매핑

| variant | 기본 태그 | 적용 클래스 | 용도 |
|---------|----------|-------------|------|
| `h1` | `<h1>` | text-4xl font-bold leading-tight tracking-tight | 페이지 제목 |
| `h2` | `<h2>` | text-3xl font-bold leading-tight tracking-tight | 섹션 제목 |
| `h3` | `<h3>` | text-2xl font-semibold leading-tight | 서브섹션 제목 |
| `h4` | `<h4>` | text-xl font-semibold leading-normal | 카드/패널 제목 |
| `body` | `<p>` | text-base font-normal leading-normal | 기본 본문 |
| `body-sm` | `<p>` | text-sm font-normal leading-normal | 작은 본문 |
| `label` | `<span>` | text-sm font-medium leading-none | 폼 레이블 |
| `caption` | `<span>` | text-xs font-normal leading-normal text-text-muted | 캡션 |

```tsx
// variant = 시각적 스타일, as = HTML 태그 (독립 제어)
<Typography variant="h1">페이지 제목</Typography>
<Typography variant="h1" as="h2">h1 스타일이지만 h2 태그</Typography>
<Typography variant="caption">2026-03-02 · 힌트 텍스트</Typography>
```
