# 모듈 슬롯 시스템 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** 대시보드가 banner를 직접 import하지 않도록 슬롯 시스템(ModuleSlot + glob codegen 레지스트리)을 도입해, banner 제거 시 frontend가 깨지지 않게(self-contained) 만든다.

**Architecture:** `ModuleSlot` 컴포넌트가 codegen으로 생성된 `slot-registry.generated.ts`를 읽어 슬롯별 모듈 컴포넌트를 렌더한다. 각 모듈은 `features/<id>/dashboard-slots.tsx`에서 `dashboardSlots`를 export하고, glob codegen이 설치된 모듈만 모은다. 대시보드는 빈 슬롯만 둔다.

**Tech Stack:** Next.js, React, tsx codegen 스크립트, Node fs(글롭).

> 설계: `docs/specs/2026-06-04-module-slot-system-design.md`. 최소 슬롯 2개(`dashboard-top`, `global-popup`).

## Task 1: codegen 스크립트 + 초기 레지스트리 생성

**Files:** `scripts/gen-slot-registry.ts`, `apps/core-frontend/src/shared/components/slot-registry.generated.ts`(생성됨)

- [ ] **Step 1: gen-slot-registry.ts 작성**

`apps/core-frontend/src/features/*/dashboard-slots.tsx`를 스캔해 존재하는 모듈만 import하는 generated 파일을 만든다. 슬롯명은 고정 2개.

```typescript
import * as fs from 'node:fs';
import * as path from 'node:path';

const ROOT = process.cwd();
const FEATURES_DIR = 'apps/core-frontend/src/features';
const OUT = 'apps/core-frontend/src/shared/components/slot-registry.generated.ts';
const SLOT_NAMES = ['dashboard-top', 'global-popup'] as const;

function findSlotModules(): { id: string; importPath: string }[] {
  const base = path.join(ROOT, FEATURES_DIR);
  const found: { id: string; importPath: string }[] = [];
  for (const id of fs.readdirSync(base)) {
    const file = path.join(base, id, 'dashboard-slots.tsx');
    if (fs.existsSync(file)) {
      found.push({ id, importPath: `@/features/${id}/dashboard-slots` });
    }
  }
  return found.sort((a, b) => a.id.localeCompare(b.id));
}

function generate(): string {
  const mods = findSlotModules();
  const imports = mods
    .map((m) => `import { dashboardSlots as ${m.id}Slots } from '${m.importPath}';`)
    .join('\n');
  const slotLines = SLOT_NAMES.map((slot) => {
    const items = mods
      .map((m) => `${m.id}Slots['${slot}']`)
      .join(', ');
    return `  '${slot}': [${items}].filter(Boolean) as SlotEntry[],`;
  }).join('\n');

  return `// AUTO-GENERATED by scripts/gen-slot-registry.ts — DO NOT EDIT
import type { ReactNode } from 'react';
${imports}

export type SlotName = ${SLOT_NAMES.map((s) => `'${s}'`).join(' | ')};
export type SlotEntry = () => ReactNode;

export const SLOT_REGISTRY: Record<SlotName, SlotEntry[]> = {
${slotLines}
};
`;
}

fs.writeFileSync(path.join(ROOT, OUT), generate());
console.log(`✅ slot-registry 생성: ${findSlotModules().length}개 모듈`);
```

> 모듈이 0개여도 유효한 빈 레지스트리를 생성(import 없음, 각 슬롯 빈 배열). `as SlotEntry[]`로 빈 배열 타입 보장.

## Task 3: ModuleSlot 컴포넌트

**Files:** `apps/core-frontend/src/shared/components/module-slot.tsx`

- [ ] **Step 1: module-slot.tsx 작성**

```tsx
'use client';

import { SLOT_REGISTRY, type SlotName } from './slot-registry.generated';

export function ModuleSlot({ name }: { name: SlotName }) {
  const entries = SLOT_REGISTRY[name] ?? [];
  return (
    <>
      {entries.map((Entry, i) => (
        <Entry key={i} />
      ))}
    </>
  );
}
```

> `Entry`는 `() => ReactNode` 함수형. `<Entry key={i} />`로 렌더(컴포넌트로 취급). 만약 타입상 함수 호출이 더 적절하면 `{entries.map((entry, i) => <Fragment key={i}>{entry()}</Fragment>)}`로. 빌드 시 둘 중 동작하는 쪽으로(JSX 컴포넌트 호출 규약 확인).
